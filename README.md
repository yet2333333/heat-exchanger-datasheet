# 换热器 GB 标准设计生成 + EDR 验证

> 按 GB/T 28712、GB/T 151 自动选型计算，并把 Aspen EDR 的仿真结果拉进来做对比验证——整个过程在一个浏览器页面里完成。

一个**单文件、零依赖**的换热器设计辅助工具。双击 `index.html` 就能跑，不需要装 Python、不需要联网、不需要后端服务。

作者是化工工艺工程师，这个工具解决的是他自己做换热器设计时反复遇到的两件事：

1. **选型要一遍遍翻标准**——面积、余量、管长、CUT 比、流速、管数，每个都要查 GB/T 28712 的推荐区间
2. **EDR 仿真结果和标准推荐值对不对得上，要人工逐个比对**——20 多个参数，一上午就过去了

于是把这两件事都做成了自动化。

## 功能

### ① 条件输入

| 模块 | 说明 |
|------|------|
| 换热类型 | 换热目的、工位号、换热器型式（固定管板式 / 浮头式 / U 形管式 / 板式 等） |
| 工艺物料流股 | 介质名称、进出口温度、操作压力、进料相态、流量、热负荷、LMTD、结垢倾向、粘度、毒性、固体颗粒、CAS 号 |
| 另一侧流股 | 公用工程侧（蒸汽 / 循环水 / 冷冻水）的温度、压力、相态、允许压降 |
| 物性自动填充 | 填 CAS 号自动带出分子量、密度、比热、黏度、热导率、沸点、临界温度 |
| **Aspen Plus 一键导入** | 粘贴模拟结果，自动解析成输入参数 |
| 现场条件 | 安装空间、检修条件、介质腐蚀性等现场约束 |

### ② GB 标准设计生成

| 模块 | 说明 |
|------|------|
| 标准设计结果 | 换热面积、设计余量、管长、管数、管程数、壳径 |
| 详细参数表 | 工艺/结构参数、传热/流体参数两栏对照 |
| 管束布置概要 | 管径、管中心距、排列方式、折流板间距与切口 |
| 面积余量评估 | 判断余量是否落在合理区间 |
| 型式推荐 + GB 151 检验 | 按工况推荐换热器型式，并给出标准符合性检验 |
| 智能选型分析 | 给出选型建议与理由 |

### ③ EDR 上传对比

| 模块 | 说明 |
|------|------|
| EDR 解析 | 直接读 Aspen EDR 导出的文件，提取全部关键参数 |
| EDR vs GB 对比 | 逐项列出仿真值与标准推荐值的差异 |
| 综合评估报告 | 自动生成结论：哪些参数偏离、偏离多少、要不要调整 |

### ④ 现场评估

按现场安装与检修条件做适用性评估，给出结果总览与综合建议。

### ⑤ 条件图表导出

把 EDR 数据一键导出成**条件图表 xlsx**（设备数据表格式：工艺参数、结构参数、管口表、备注）。

> 导出用的是内嵌的 xlsx 模板——**只替换单元格数值，样式、主题、合并单元格、行高 100% 保留**。
> 仓库里的模板是通用空白版，你可以换成自己单位的模板：保持同样的 sheet 结构即可。
> 所有带单位的字段会按条件表左侧标注的单位统一输出（压力 MPa / 温度 ℃ / 密度 kg/m³ / 黏度 cP），
> 读取 EDR 里每个标量的 `<uom>` 标签做感知换算。

## 怎么用

**最简单**：下载 `index.html`，双击用浏览器打开。

**在线版**：如果仓库开启了 GitHub Pages，直接访问页面即可。

**完整流程**：

```
1. 条件输入  → 填工况（或用 Aspen Plus 导入）
2. GB设计生成 → 看选型结果和标准检验
3. EDR上传对比 → 上传 EDR 文件，自动比对
4. 现场评估  → 确认能不能落地
5. 导出条件图表 → 生成 xlsx
```

**环境要求**：任何现代浏览器（Chrome / Edge / Firefox）。**零依赖、零安装、可离线运行。**

## 技术要点

**1. 纯前端，零依赖**

全部逻辑用原生 JavaScript 实现，没有引入任何框架或第三方库——这样单个 HTML 文件可以直接微信发给同事，打开就能用。

**2. EDR 文件的解析**

Aspen EDR 导出的文件是结构化文本，逐层提取设备参数、流股数据、物性数据，再映射到内部数据结构。

**3. xlsx 的浏览器端生成**

Excel 文件本质是一个 ZIP 包。这里把模板的各个部件（`styles.xml` / `theme1.xml` / `sheet1.xml` …）以 base64 内嵌在页面里，
导出时**只替换数据单元格的值**，其余部件原样保留，再用自实现的 CRC32 + ZIP 打包逻辑生成文件下载。

好处是**样式 100% 不失真**——合并单元格、边框、字体、行高全部沿用模板，不会出现"导出的表格式跟原模板不一样"的问题。

**4. 单位智能换算**

读取 EDR 中每个数值的 `<uom>` 标签感知原始单位，按条件表要求的目标单位换算；标识缺失或未识别时按目标单位原值输出。

**5. 中英文物质名映射**

EDR 输出的组分名常是英文（如 `FURFURAL`），内置映射表自动转成中文，便于填写介质名称。
